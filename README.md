# pair-wise-yf-46 国际新闻直播编排与突发插播控制台

源提示词摘要：面向导播、主编、字幕和演播室岗位的直播串联单，维护新闻片、连线、嘉宾、口播和广告；支持时长重算、硬时间风险、突发插播、角色权限、操作历史、一键撤回和断网应急队列。

## 技术栈

React19、TypeScript、Vite、Ant Design、Redux Toolkit、RTK Query、React Router、React Hook Form、Zod、i18next、date-fns、dnd-kit。

## 本地运行

```bash
npm install
npm run dev
npm run build
```

开发端口：62011

## 岗位接管与离线队列规则

- **接管**：主编在「岗位接管」页离岗后，导播立即接管插播审批；未确认的插播申请保持"待审"，离线队列条目的 `ownerRole` 始终保留提交岗位（如字幕），接管不改变归属。
- **30 秒心跳窗口**：主编重新上线后开始 30 秒倒计时；窗口内上报心跳（`heartbeat`）即撤销接管、审批回归主编；超时未恢复则窗口关闭、导播继续审批，迟到心跳不再撤销。
- **同条同时修改**：双方修改同一串联单条目时，确认时间（`confirmedAt`）较晚的版本写入串联单，另一版进入「冲突箱」，可取回处理。
- **断网对账**：断网期间的审批进入本地应急队列并标注原岗位；链路恢复后在「应急队列」页逐条对账——硬时间已过而内容尚未播出的插播撤下、保留原排期，冲突原因（`硬时间已过内容未播`）与双方版本进入冲突箱，全部对账记录留档。
